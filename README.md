# MichaelMylettComp415Project4

Michael Mylett

Upon running the program, a database is created with individual tables for our salary data, rent data, house price data, and state data. These are then all populated with data pulled from 4 corresponding Excel sheets (the fourth one, for the states, was made by me). Every table is populated with all data from its corresponding spreadsheet, except for the house price table, which is only filled with data from the year 2026. Most decisions for what datatypes to use for the tables were arbitrary, like my interchangeable use of TEXT and VARCHAR datatypes (which, as far as I can tell, would still function the same even if I swapped all of them. I only used VARCHAR because I forgot how it worked from my old database class and was mostly working from memory). This entire process is automatic; no user input is required other than pressing the start button with all necessary spreadsheets inside the file directory (you don't even need a database file, since the program just creates one if it can't find anything).

One odd thing I noticed with my program was that, at a certain point, one of my tables' columns was being filled with random garbage numbers. Though I realized this was just because I had accidentally set that column to be NOT NULL, I am still confused by the fact that it just filled it with random numbers rather than giving an error of some kind.
